Optional vendor CAN FD library
------------------------------

The optional libcanbus.so / HCanbus.dll implementation is loaded dynamically
at runtime. The vendor binary is not included in this repository or installed
by this project's CMake rules. Users must obtain it separately and comply
with the vendor's applicable license and distribution terms.

Optional PCAN-Basic components
-----------------------------

PCAN-Basic is loaded dynamically. The PEAK driver, PCANBasic.dll and vendor
headers are not distributed by this project. Users obtain matching components
from PEAK and comply with the applicable vendor license and distribution terms.
The independently declared ABI fixtures under tests/ are test components and
are not installed or included in runtime archives.
Source: https://www.peak-system.com/products/software/development-packages/pcan-basic/?L=1
